#
# The previous file pinned numpy==1.26.4, which publishes no wheel for Python
# 3.13 — so `pip install -r requirements.txt` could not succeed on a 3.13
# interpreter, and a developer on that version silently ended up running
# numpy 2.x / pandas 2.3 locally while CI and the Docker image ran 1.26 / 2.2.
# Local runs then validated a stack that never shipped. These ranges resolve to
# the same versions everywhere and stay installable on 3.11 through 3.13.
